# Simulador de Régua de Cálculo

Esse projeto é um site simples feito utilizando HTML, CSS básico e JavaScript básico para simular o funcionamento de uma régua de cálculo. Ele foi apresentado como parte do projeto final da disciplina de Evolução Histórica da Computação, ministrada pelo professor Claudio Fabiano Motta Toledo. O site pode ser acessado [aqui](slide-rule-simulator.vercel.app).
